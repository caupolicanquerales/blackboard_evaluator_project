# Rules
Test code only at `path`; never `src/main`/`pom.xml`. Deps: pom-declared (missing => report). Imports: org.junit.jupiter.api.*, static AssertJ; banned org.junit.*, javax.*, Hamcrest. Class `<Export>Test`; package = ast_hints.package; NO app-context test unless the intent or a wiring/composition task names it (see Spring). `ast_hints.methods[].semantics` are contract clauses: assert exactly the nullability/initial-state they state, and THEY BIND YOUR FIXTURES - every constructor argument of a collaborator you build must satisfy that constructor's `semantics` (or its named factory); an out-of-range literal throws in your own helper before the unit runs, and no implementation can pass it. `method_condition_expected`; one behavior/test; <15 lines; AAA; no shared state.
# Assertions
isEqualTo; hasSize(n).containsExactly(...); isPresent().contains(v); usingRecursiveComparison(); BigDecimal.isEqualByComparingTo; assertAll; assertThatThrownBy(...).isInstanceOf(T); @ParameterizedTest + @CsvSource/@EnumSource/@MethodSource.
# Doubles
Mock only out-of-unit collaborators; never records/value objects/your unit. @ExtendWith(MockitoExtension.class), @Mock/@InjectMocks; when/thenReturn/thenThrow; verify(m,never()), ArgumentCaptor; strict stubs (lenient() only if intent demands); no mockStatic/mockConstruction unless named. A when() target is ALWAYS an instance method on a MOCK INSTANCE - never a static member (`when(CorrelationContext.contextKey())` is a real static call Mockito rejects for EVERY payload: an unsatisfiable frozen test); for constants-like members assert the REAL value of the class or stub the pinned PORT. Simple ports: in-memory fake OK. Reactive: StepVerifier, never .blockFirst().
# Spring (only if intent requires)
- Web slice: @WebMvcTest + @MockBean (Boot 3.x)/@MockitoBean (3.4+), MockMvc - check pom. A cross-cutting `@Configuration` you `@Import` (a security chain) drags its bean-method's concrete project types into YOUR slice: double each as the table pins it; a needed type no table carries is a PLAN HOLE you report - never drop the import to make the context load (an unguarded slice proves nothing about its guard), never harvest the name from delivered sources.
- Repository/adapter gates: persistence slice only - @DataJpaTest or @DataR2dbcTest + the embedded substitute EXECUTING the real `db/migrations/V*.sql` (path read or @Sql; never retyped DRL drift). SUBSTITUTE CREATOR AND READER SHARE CREDENTIALS: a fixture seeding over JDBC/Flyway with an explicit user needs the SAME identity in the R2DBC URL (`;USER=sa;PASSWORD=`) - a bare reader dies `[28000] Wrong user name or password` at the green gate, invisible to a compile-error red. AGGREGATE READS: `MAX()/COUNT()` decode as `Number`/`Integer` - asking the codec for `Long.class` raises "Cannot decode value of type"; convert in Java (`.get("r", Number.class).longValue()`), the assertion value never moves. COLLECTION-OF-COLLECTIONS: never chained `flatExtracting`/`extracting` lambda stages - AssertJ degrades the element to `java.lang.Object` from the first hop (an uncompilable frozen test); project through typed stream calls into a local and assert ONCE on the local.
- Config-file tests assert through the loader the RUNTIME uses - Spring: `org.springframework.boot.env.YamlPropertySourceLoader` (documents, flattened keys, profile by `spring.config.activate.on-profile`) - never raw SnakeYAML/Jackson + a hand-rolled flatten; the oracle reads PROPERTY PATHS, not the file's serialization shape (nested and flat spellings must both pass: the loader is the contract, indentation is not).
- Context runners (ApplicationContextRunner, @SpringBootTest): supply EVERY property the booting contract needs to CONSTRUCT what you assert (operational values from the tables' config paths, fixture credentials from fixture entries). A framework type whose constructor rejects emptiness (`Assert.notEmpty`) has no legal empty state: assert seeded behavior OR the named failure - never "bean exists" over an empty store.
- END-TO-END SLICES ISOLATE THEIR STATE: every case shares one substitute and one context - global `COUNT(*)`/`MAX()` EQUALITY is forbidden (pass/fail would ride JUnit method order, which is not a contract); assert a RELATIVE delta, scope every query by an identity the case itself seeded, or drive the cleanup the support contract provides.
# Coverage & red
Every intent constraint: null/blank/negative/range/duplicate/boundary. Injected Clock; @TempDir; no network/system env. Expected red = compile_error (missing symbols) or assertion_failure; passing => fix the test. Nested types via enclosing type.
# Observability units (audit / step logs / metrics / correlation)
- Audit: recording fake (or ArgumentCaptor); assert EVERY tabled field (shape from ast_hints, nullability from `semantics`). Logs: each claimed `observability.step_logs` entry is a FROZEN duty of THIS test - Logback `ListAppender<ILoggingEvent>` on the owning logger, assert the captured event and its STRUCTURED fields; never formatted-string equality or `contains` on prose. Metrics: `SimpleMeterRegistry`, `registry.get(name).counter().count()`/`timer()` - the NAME comes from `ast_hints.meters`, VERBATIM as the table owns or uses it. HTTP: the (method, path) under test comes from `ast_hints.routes` - never a URI the test invents. Correlation: the requestId appears in the records/events this test already collects.
- A REGENERATED (reopened) test takes its oracle from the TASK RECORD - intent + `ast_hints` as QUEUED - never from the delivered implementation beside it in the tree: asserting what shipped launders the implementation's drift into frozen contract. A name the tables omit is a plan hole to report, not a string to harvest.
