# Rules
Test code only at `path`; never `src/main`/`pom.xml`. Deps: pom-declared (missing => report). Imports: org.junit.jupiter.api.*, static AssertJ; banned org.junit.*, javax.*, Hamcrest. Class `<Export>Test`; package = ast_hints.package; NO @SpringBootTest. `ast_hints.methods[].semantics` notes are contract clauses: assert exactly the nullability/initial-state they state (e.g. pre-validation value is the shipped constant, never null). The same notes BIND YOUR FIXTURES: when a test constructs a collaborator's type, every constructor argument must satisfy that constructor's tabled `semantics` (or come from its named factory) - an out-of-range literal (`0` where the table says `>=1`) makes the frozen test throw in its own helper before reaching the unit under test, and no implementation can pass it. `method_condition_expected`; one behavior/test; <15 lines; AAA; no shared state.
# Assertions
isEqualTo; hasSize(n).containsExactly(...); isPresent().contains(v); usingRecursiveComparison(); BigDecimal.isEqualByComparingTo; assertAll; assertThatThrownBy(...).isInstanceOf(T); @ParameterizedTest + @CsvSource/@EnumSource/@MethodSource.
# Doubles
Mock only out-of-unit collaborators; never records/value objects/your unit. @ExtendWith(MockitoExtension.class), @Mock/@InjectMocks; when/thenReturn/thenThrow; verify(m,never()), ArgumentCaptor; strict stubs (lenient() only if intent demands); no mockStatic/mockConstruction unless named. A when() target is ALWAYS a call on a MOCK INSTANCE's instance method: never stub a static utility member (`when(CorrelationContext.contextKey())` is a real static call, no mock is involved, Mockito rejects it for EVERY payload - an unsatisfiable frozen test). When the table pins constants-like members on a collaborator class, assert the REAL value of that class or stub the pinned PORT instead. Simple ports: in-memory fake OK. Reactive: StepVerifier, never .blockFirst().
# Spring (only if intent requires)
Web: @WebMvcTest + @MockBean (Boot 3.x)/@MockitoBean (3.4+), MockMvc - check pom. Repository/adapter gates: persistence slice only - @DataJpaTest (JPA) or @DataR2dbcTest (reactive) + embedded H2/r2dbc substitute, the schema EXECUTING the real `db/migrations/V*.sql` contents (read from the module-root-relative path - @Sql or a file read; NEVER retyped DDL, which drifts silently from the file it claims to mirror). CONFIG-FILE tests assert through the loader the RUNTIME uses - Spring: `org.springframework.boot.env.YamlPropertySourceLoader` (count the documents, read the flattened keys, locate the profile document by `spring.config.activate.on-profile`) - NEVER raw SnakeYAML/Jackson plus a hand-rolled flatten: a parser the test builds itself is an oracle that passes on any file it believes, including one Spring would not bind (seed-002 rerun 2026-11-13: the same config duty was pinned strong in one drain and improvised weak in the next - only a rule keeps the oracle at the runtime surface). @SpringBootTest is FORBIDDEN for a unit gate (boot-wide context belongs to stage 4 assembly, and a whole-graph demand on one unit lands every graph defect on that bystander) unless the task IS composition/wiring or its intent names it.
# Coverage & red
Every intent constraint: null/blank/negative/range/duplicate/boundary. Injected Clock; @TempDir; no network/system env. Expected red = compile_error (missing symbols) or assertion_failure; passing => fix the test. Nested types via enclosing type.
# Observability units (audit / step logs / metrics / correlation)
Audit port fakes: implement the port with a recording fake (or ArgumentCaptor) and assert EVERY tabled field of the captured record (actor, action, outcome, timestamp, correlationId) - the shape comes from ast_hints, nullability from its `semantics`. Logs: every entry in the task's `observability.step_logs` claim is a FROZEN assertion duty of THIS test: attach a Logback `ListAppender<ILoggingEvent>` to the owning class's logger, assert the event exists for the claimed boundary and its STRUCTURED fields (marker, MDC/argument values); never `event.getFormattedMessage()` string equality or `contains` on prose. A claimed step log with no captured-event assertion is an unfilled contract. Metrics: inject a `SimpleMeterRegistry`, then `registry.get("tabled.meter.name").counter().count()` / `timer()` totals - the meter NAME is the contract from ast_hints. Correlation: assert the requestId field appears in the captured records/events the same test already collects. Expected red stays the same: missing symbols or assertion failures on these surfaces.
